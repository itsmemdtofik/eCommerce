# 🛒 eCommerce Platform

## Overview

This is a simple and responsive eCommerce platform that allows users to browse products, register, login, and add items to the shopping cart. It features a dynamic user interface for managing shopping experiences in a clean and modern design.

## Features

- 🔒 **User Authentication**: Secure login and registration system for customers.
- 🛍️ **Product Browsing**: View and search for products on the homepage.
- 🛒 **Cart Management**: Add products to the cart, adjust quantities, and proceed to checkout.
- 📱 **Responsive Design**: Fully optimized for mobile and desktop users.
- 🧾 **Order Summary**: Review the order details before placing it.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Django
- **Security**: HMAC, SHA-256 for encryption
- **Database**: SQLite3
- **Version Control**: GitHub for repository management

## How to Install and Run Locally

1. Clone the repository:

    ```bash
    git clone https://github.com/itsmemdtofik/eCommerce
    cd ecommerceapp
    ```

2. Run the project locally:

    ```bash
    python manage.py runserver
    ```

3. Open your browser and navigate to:

    ```
    http://localhost:8000
    ```
